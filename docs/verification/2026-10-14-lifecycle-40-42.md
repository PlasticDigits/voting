The isolated database used a loopback ephemeral PostgreSQL instance with a
`voting_test_*` name, explicit destructive opt-in, required-job mode, and catalog
marker `cl8y-voting-ephemeral-test`. After the first migration run revealed
schema-dependent migration history, the writer migrator was pinned to public
search_path and fresh infrastructure was used to repeat the suite. Concurrent
foreign-key key-share/proposal-lock deadlocks were reproduced, fixed using
`FOR NO KEY UPDATE`, and the full race suite repeated successfully.

A filesystem-wide `gitleaks --no-git` scan also read untracked Rust build metadata
and flagged nine embedded dependency documentation private-key markers, not
source credentials. The staged source scan above passed. Do not commit build
outputs or use that artifact scan as evidence of a source secret.
